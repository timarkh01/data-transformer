# Трансформер
 
Программа для конвертации данных между форматами: **TXT, CSV, JSON, Excel, SQL**.
 
## Функционал
 
- Чтение данных из TXT, CSV, JSON, Excel, SQL
- Запись данных в TXT, CSV, JSON, Excel, SQL
- Если файл уже существует, то данные дописываются в конец, а не перезаписываются (кроме SQL, где при создании файла с таким же названием он будет перезаписан)
- Формат данных не зависит от количества и названий колонок
## Формат данных для каждого файла
 
### TXT
 
Каждая запись = блок в фигурных скобках, внутри строки `ключ: значение`.
 
```
{
name: Timofey
address: abc str.
phone_number: +7123
date_of_birth: 12.12.2012
}
 
{
name: Ivan
address: def str.
phone_number: +7987
date_of_birth: 01.01.2000
}
```
 
### CSV
 
Обычный CSV с заголовком в первой строке (названия колонок = ключи словаря), разделитель = запятая.
 
```
name,address,phone_number,date_of_birth
Timofey,abc str.,+7123,12.12.2012
Ivan,def str.,+7987,01.01.2000
```
 
### JSON
 
Список объектов (массив словарей):
 
```json
[
    {
        "name": "Timofey",
        "address": "abc str.",
        "phone_number": "+7123",
        "date_of_birth": "12.12.2012"
    },
    {
        "name": "Ivan",
        "address": "def str.",
        "phone_number": "+7987",
        "date_of_birth": "01.01.2000"
    }
]
```
 
### Excel (.xlsx)
 
Обычная таблица: первая строка = заголовки (ключи), остальные строки = данные, каждая колонка = один ключ.
 
| name | address | phone_number | date_of_birth |
|---|---|---|---|
| Timofey | abc str. | +7123 | 12.12.2012 |
| Ivan | def str. | +7987 | 01.01.2000 |
 
### SQL
 
Это файл базы данных SQLite (с расширением `.sql`). Внутри создаётся таблица с именем файла с заглавной буквы (`filename.capitalize()`), например для `info.sql` — таблица `Info`:
 
```sql
CREATE TABLE Info (
    id INTEGER PRIMARY KEY,
    name TEXT,
    address TEXT,
    phone_number TEXT,
    date_of_birth TEXT
)
```
 
Колонка `id` создаётся автоматически (в самих данных её быть не должно), остальные колонки — все ключи из словарей, тип всегда `TEXT`. Просмотреть содержимое можно через DB Browser for SQLite.
